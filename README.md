# 🔗 Social Links Profile

A minimal and responsive social links profile card that displays contact and social media details in one clean page. Solution to a Frontend Mentor challenge.

## 📌 Features

- Clean single-page profile card layout
- Social media and contact links
- Fully responsive design
- Semantic HTML5 markup

## 🎯 Frontend Mentor challenge

This project is a solution to the [Social Links Profile challenge](https://www.frontendmentor.io) on Frontend Mentor.

## 🚀 Run locally

```bash
git clone https://github.com/Technology-World/social-links-profile-main.git
```

Open `index.html` in your browser or use Live Server in VS Code.
